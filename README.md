# Greenfield Academy Automated Report Card System

**Project Type:** Data Analytics & Reporting Automation  
**Industry:** Education  
**Tools:** Microsoft Excel  
**Skills:** Data Cleaning, Data Validation, Formula Automation, Data Analysis, Reporting

---

## Project Overview

The Greenfield Academy Automated Report Card System is a data analytics and reporting automation project designed to improve student performance reporting and reduce manual data entry.

The system uses a formula-driven lookup approach to retrieve student information through a unique Student ID and generate a consolidated report containing academic performance, attendance, and administrative details.

The project demonstrates how data analytics and spreadsheet automation can improve reporting accuracy, operational efficiency, and data-driven decision-making in education.

---

## Business Problem

Manual report card preparation can lead to:

- Repetitive data entry and calculation errors.
- Delays in retrieving student performance information.
- Difficulty consolidating academic and attendance records.
- Limited visibility into student performance for timely intervention.

---

## Project Objectives

- Automate student report card generation using Student ID lookup.
- Calculate average scores and academic performance status.
- Monitor student attendance and attendance percentage.
- Consolidate academic and administrative information into one report.
- Improve data accuracy by replacing hard-coded report values with formulas.

---

## Dataset Overview

The dataset contains student-level academic and administrative information.

| Data Category | Key Fields |
|---|---|
| Student Information | Student ID, Full Name, Grade Level |
| Academic Performance | Mathematics, English, Science, Social Studies, Average Score, Pass/Fail Status |
| Attendance | Days Present, Total School Days, Attendance % |
| Administration | Tuition Fee, Class Teacher |

---

## Analytical Process

### 1. Data Organization

Structured student information into a centralized dataset containing academic, attendance, and administrative records.

### 2. Data Validation

Checked score calculations, attendance figures, and Student ID consistency to improve data reliability.

### 3. Formula Automation

Implemented lookup formulas to retrieve student records dynamically using a unique Student ID.

### 4. Performance Analysis

Calculated average scores and evaluated student academic status based on the reporting criteria.

### 5. Report Generation

Combined student information, academic results, attendance, and administrative details into an automated report card.

---

## Key Findings

The pilot analysis of Student ID `GA-2026088` revealed the following:

| Metric | Result |
|---|---:|
| Average Score | 63.8 |
| Attendance | 97.5% |
| Academic Status | PASS |
| Highest Subject Score | Mathematics – 88 |
| Lowest Subject Score | Social Studies – 52 |

### Performance Insight

The student demonstrated strong attendance and passed the academic assessment. However, the variation in subject scores highlights an opportunity for targeted academic support, particularly in Social Studies.

The automated reporting system provides a foundation for:
